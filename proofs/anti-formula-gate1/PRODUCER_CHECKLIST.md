# HOOK//10 A / B1 / C: producer review checklist

About ten minutes. Page: <https://claude.ai/artifact/NqkTnsuBTMzkzvDGT2Hy9e>. The versions appear as X, Y and Z in
a shuffled order. Do not reveal the names until step 4.

## 1. Cold pass (headphones)

- [ ] Let X, Y and Z each loop three or four times.
- [ ] Which one do you want to hear again? (None is allowed.)
- [ ] Stop the player. Which hook can you hum back?

## 2. Close pass

- [ ] Which sounds most like a record and least like a loop?
- [ ] Which has the best pocket: the bass and clock feel?
- [ ] In which does bar 4 land hardest and pull you back to bar 1?
- [ ] Which has the most character: the one you would describe to someone?
- [ ] Does anything sound wrong, broken or generic? Note the letter and the bar.

## 3. Second system

- [ ] Repeat step 1 on a phone speaker or in the car. Did your answer change?

## 4. Reveal, then judge the decision in C

Tap "Reveal names". C is A with three notes removed: in bar 3 the voice sings the cry and does not come home.

- [ ] Did you notice the gap in bar 3 before you knew it was there?
- [ ] Does it read as intended (a held breath), as a mistake (a dropped phrase), or as nothing?
- [ ] Does the first note of bar 4 feel like an arrival in C? More, less or the same as in A?
- [ ] Is the hook still the hook in C? Is the pocket still the pocket?
- [ ] Against B1: which do you prefer, development by adding (B1) or by taking away (C)? Or neither?

## 5. Verdict (one line each)

- [ ] Keep: A / B1 / C / none.
- [ ] Is "memory, then one intended decision, with a ledger" worth a second gate? Yes / no / only if ___.
- [ ] If C fails: is it the idea (restraint here) or the execution (too long a gap, wrong bar, wrong notes withheld)?

## 6. Ten minutes later, without replaying

- [ ] Which one do you still have in your head?

Send the answers back with the page's "Copy my answers" button, or in your own words. A rejection of all three is
a useful result.
