# V12 SIGNATURE · pack v1

Sixteen original instruments for DaemonV12 v0.7: two kicks, snare, clap, two
hats, a held sub, a mid-bass, two leads, two pads, a synthetic choir vowel, a
bell, a riser and an impact. Dark, cinematic, hypnotic; home key **A minor**.
Every WAV is generated by [`scripts/generate-v12-signature.ts`](../../scripts/generate-v12-signature.ts)
from numeric DSP parameters, and plays through the existing `sampler` and
`drumkit` instruments. No engine change is needed or made.

**Status:** version 1.0.0, additive and independent. It is not copied by
`daemonv12 init`, not in the npm package, and not part of BANGER LAB 001's
frozen palette. **Licensing is pending the owner's declaration**; see
[PROVENANCE.md](PROVENANCE.md). Measurements and the listening checklist are in
[REPORT.md](REPORT.md).

## The identity

- **Locked low end.** SUB HAMMER, IRON PULSE, CONVERGENCE and REACTOR all settle
  on A1 = 55 Hz *in phase with ABYSS* (each pitch drop adds a whole number of
  cycles). Trigger any of them with ABYSS on the same tick and the fundamentals
  add (measured correlation 0.81–0.95) instead of cancelling.
- **CHROME.** A minor-third bell (hum, prime, minor-third tierce, quint, nominal)
  plus eight inharmonic modes. It is the bell, the hats' metal, the snare's ring,
  IRON PULSE's tick, the riser's shimmer and the impact's tail.
- **Ghost vowel.** One dark "oh" and one open "ah". REACTOR growls through it,
  PHANTOM is voiced by it, SPECTER sings it.

## Playing it in v0.7

**Pitch.** `playbackRate = 2^(semitones/12)` from the root. All roots are A
except PHANTOM (E5, the centre of the A4–A5 lead octave, so its vibrato stays
3.4–6.8 Hz across that octave). Common rates: −12 → 0.5, −7 → 0.66742,
−5 → 0.749154, −4 → 0.793701, −2 → 0.890899, +3 → 1.189207, +5 → 1.33484,
+7 → 1.498307, +12 → 2.

**Hold and release.** Sustained sounds have no loop: give every held note a
`gate` (its musical length) and an `envelope`. A higher note lasts shorter
(seconds / rate); stay inside the *Hold* column.

```json
{"start":"9:1","playbackRate":0.793701,"gate":"1/1","envelope":{"attackSeconds":0.004,"releaseSeconds":0.06}}
```

**Chords.** Stack notes at the same `start` on one sampler track (AFTERGLOW,
SPECTER), or play one EVENT HORIZON note per chord: it is an open fifth with no
third, so A2 works under A minor and A major alike.

**Skip a swell or bloom.** `offsetSeconds` starts inside the source; add an
attack ramp. EVENT HORIZON `offsetSeconds: 1.6` starts at full level; SPECTER
1.2 is the "oh", 2.2–2.8 the open "ah"; ABYSS 0.12 skips its harmonic bloom for
tied legato notes. ASCENSION `offsetSeconds: 6 − build seconds` shortens the
riser and keeps its arrival on the target downbeat.

**Kit and chokes.** `assets/v12-signature/kit.json` maps the seven percussion
sounds by name and GM-style pitch (35 iron-pulse, 36 sub-hammer, 38
titanium-crack, 39 neon-clap, 42 ghost-tick, 46 open-circuit, 53
chrome-strike). Put `"chokeGroup":"hats"` on both hats so a tick closes the
open hat; `"kick"` and `"snare"` keep fast patterns and rolls clean.

### Recipes (copied from the showcase)

| Gesture | Note fields |
|---|---|
| Tight groove kick | `{"pitch":"sub-hammer","gate":"1/16","envelope":{"attackSeconds":0.001,"releaseSeconds":0.04},"chokeGroup":"kick"}` |
| Drop kick | SUB HAMMER `gate "1/8"` + IRON PULSE full, same tick, both `chokeGroup "kick"` |
| Rolling bass | ABYSS + REACTOR on the three sixteenths after each kick, `gate "1/16"`, release 0.02–0.025 |
| Off-beat growl | REACTOR on each `+1/8`, `gate "1/16"`, release 0.04, track high-pass 110 Hz |
| Hypnotic cell | SIGNAL sixteenths cycling three chord tones (A4 E5 C5 over Am), `gate "1/16"`, release 0.04, track delay 3/16 note |
| Hook note | PHANTOM `gate` = note length, `envelope {0.005, 0.12}`; hold over 0.5 s to hear the vibrato bloom |
| Pump | Track `automation.gainDb`: 1/64 before each beat at the base level, −9 dB on the beat, recover over a dotted sixteenth |
| Build | ASCENSION at `offsetSeconds 2.25` two bars (128 BPM) before the drop, TITANIUM CRACK rolls with `chokeGroup "snare"` |

### Mix starting points (showcase, 128 BPM)

Track gains: kick −4.5, snare −2, hats −1.5 (pan 0.18), chrome −3 (reverb
3 s, wet 0.3), ABYSS −6.5, REACTOR 0 (high-pass 110 Hz), SIGNAL −9.5 (delay
351.5625 ms, wet 0.28), PHANTOM −7 (delay 1/8, reverb 2.2 s), EVENT HORIZON −6
(high-pass 70 Hz), AFTERGLOW −9 (high-pass 120 Hz), SPECTER −3 (reverb 2.6 s),
ASCENSION −6, CONVERGENCE −6; master high-pass 25 Hz, gentle compressor
(−12 dB, 1.8:1), −0.5 dB. At velocity 1 and 0 dB, CONVERGENCE plus ABYSS on
one tick reaches +0.2 dBFS: keep low-end tracks below 0 dB.

### Render budget

Notes at the root without a glide cost nothing. Every other pitched voice costs
interpolation work: about 3.1 million taps per second at rates ≤ 1, roughly
`44100 × (ceil(69.6 × rate) + 1)` per second above. The v0.7 project limit is one
billion. The 28-second showcase uses **58.2%** of it (stacked four-note chords
and the arp are the main costs); the audition 9.7%. For longer pieces put the
most frequent notes on the roots, prefer one EVENT HORIZON note over stacked
AFTERGLOW chords, and gate tails. `daemonv12 validate` reports the budget before
any audio work.

## Use it in a workspace

Copy `assets/v12-signature/` into a workspace's `assets/` and reference
`assets/v12-signature/…` from projects there (MCP discovery finds the samples
and the kit). Redistribution waits on the license decision.

## Reproduce

```sh
npm run fixtures:v12-signature   # regenerate the 16 WAVs, kit, catalog and both projects (about 25 s)
npm run demo:v12-signature       # render the showcase with stems and MP3 into renders/v12-signature (FFmpeg)
node bin/daemonv12.js render packs/v12-signature-v1/v12-signature-audition.json --out-dir renders/v12-audition   # Node only
npm run verify:v12-signature     # fresh-process regeneration, source QC, budget, two renders each, section loudness
npm run test:v12-signature
```

`scripts/inspect-v12-signature.ts` prints the per-source measurements on its own.
