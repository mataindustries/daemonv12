# Pulse development kit

These four short WAV fixtures are original mathematical/noise sounds generated by
`scripts/generate-sample-demo.ts` with a fixed seed. No recorded or downloaded sound
sources are used. They are development/demo assets, not a commercial sample library.

The project dedicates these generated fixtures to the public domain under CC0 1.0;
you may copy, modify and reuse them, including in other projects, without attribution.

All files are 44.1 kHz, stereo, signed 16-bit PCM WAV. `kit.json` maps kick (36),
snare (38), and hat (42); `impact.wav` is used as an independent one-shot instrument.
Copy this directory under another project's `assets/` directory to reuse the kit.
Regenerate with `npm run fixtures:samples` from the repository root.
