# V0.5 synthetic voiceover activity

`synthetic-vo.wav` is an original, deterministically generated eight-second
44.1 kHz stereo PCM16 reference. Activity occupies 1.2–2.8 and 4.4–5.8 seconds;
all other regions are exactly silent. Harmonic tones, syllable modulation and
short edge fades approximate activity for envelope tests. This is not speech,
a recording, or the Shoot the Moon voiceover.

Regenerate with `npm run fixtures:v05`. The waveform is dedicated to the public
domain under CC0-1.0, following the repository's other original audio fixtures.
This asset dedication does not license the engine code.
