# Assets and provenance

Everything the project references lives under this directory (DaemonV12 resolves
`assets/…` relative to `project.json` and rejects paths or symlinks that escape it).
No recordings, downloaded samples, loops, SoundFonts, impulse responses or
copyrighted material are used. These assets are benchmark-local and are **not** part of
the shipped DaemonV12 package.

## `custom/` — generated for this submission (CC0-1.0)

Generated by `../tools/generate_assets.py` (Python 3 + numpy, float64 synthesis, seeded
xorshift32 noise, no runtime randomness, explicit PCM16 rounding, first/last frame 0).
`../custom-catalog.json` records every file's frames, tuning, role and SHA-256.
`python3 tools/generate_assets.py --verify` regenerates all 32 files in memory and
compares bytes (32/32 identical in the authoring environment: Python 3.13.16, numpy
2.5.3). Floating-point transcendental differences on other platforms could change
least-significant bits; cross-environment byte identity is not promised.

One synthesis family, "talking steel": band-limited buzz → tanh drive → five moving
vowel resonators (u → a → o) + struck free-bar steel modes (1, 2.756, 5.404, 8.933,
13.34) + a contact tick.

| Files | Tuning | Role |
|---|---|---|
| `voice-0100 … voice-1200.wav` (9 lengths) | G4 | Hook voice. Length variants exist because sampler voices have no note-off: the score builder picks the longest source that stops before the next note (monophonic phrasing). |
| `growl-0140 … growl-1000.wav` (7 lengths) | G2 | Vowel bass: same recipe, heavier drive, reese detune. Carries the hook in the payoff. |
| `sub-0120 … sub-1800.wav` (14 lengths) | G1 | Sine sub with an 808-style onset pitch drop and mild drive. |
| `halo-g5.wav` (stereo, 3.6 s) | G5 | Bowed steel: sustained modes with slow beating and bow judder. Played at rate 2/2.118926 (G6/A♭6) for tension, rate 1/1.498307 (G5/D6) when resolved. |
| `steelhat-open.wav` | — | Open hat from transposed steel modes + noise. |
| `voice-kit.json`, `growl-kit.json`, `sub-kit.json` | | Drum-kit maps of the length variants (names = file stems). |
