# DaemonV12 Composer Kit · catalogue

Generated by `node composer-kit/docs.ts`. Everything here runs on the unchanged Signature Rack (`studio-001`). The breath reed and the hand percussion come from the Timbre Lab (`timbre-lab/`); the kit registers them by itself, no flag needed.

```bash
node composer-kit/build.ts SPEC.json --check        # facts + taste check, writes nothing
node composer-kit/build.ts SPEC.json OUT_DIR        # OUT_DIR/score.json + OUT_DIR/<title>.mp3 (-16 LUFS)
node composer-kit/build.ts SPEC.json OUT_DIR --seed 9   # same spec, other seed: other fills and human timing
```

Auditions: `composer-kit/auditions/palette/<patch>.mp3` (bar 1 cold, bar 2 hot) and `composer-kit/auditions/grooves/<groove>.mp3`.

## Spec

```json
{
  "title": "Tin Saint",
  "world": "one sentence: what place is this, what is strange about it",
  "key": "D minor", "groove": "tresillo-clank", "seed": 41,
  "form": "machine-first",
  "hook": "lead",
  "voices": {
    "bass":    { "patch": "ratchet-servo" },
    "lead":    { "patch": "dead-marimba", "cell": { "bars": 2, "notes": [[0, 0.5, "D5", 0.9], [0.75, 0.25, "A4", 0.6]], "alt": [] } },
    "answer":  { "patch": "warm-throat" },
    "pad":     { "patch": "rosin-drone" },
    "texture": { "patch": "bearing-rain" }
  },
  "moves": [{ "move": "handOff", "section": "body", "to": "answer", "keep": true }]
}
```

- **voices**: `bass` is required (`{}` uses the groove's own bass patch and line). `lead`, `answer`, `pad`, `texture` are the names the forms know; other names work in your own `sections`. Optional per voice: `gainDb`, `pan`. `hat` / `perc` / `perc2` may be given only to change their patch.
- **cell**: a loop of `bars` bars. A note is `[beat, beats, pitch, velocity, options]`; beat 0 is the start of the cell, a bar is 4 beats, pitch is a name like `"Bb1"`. `alt` (optional, same format) replaces the cell on every second pass: question, then answer. A voice with no cell is a drone (tonic + fifth); a `bearing-rain` voice with no cell is rain; a bass with no cell plays the groove's line.
- **hook**: the voice that owns the hook (default `bass`). Its cell IS the hook.
- **form**: a template below. Or write `sections` yourself: `{ "id", "bars", "play": [...], "heat": 0.3 | { "bass": 0.8 }, "groove"?: "other-groove" }`. If you write `sections`, no moves are applied unless you list them.
- **play tokens**: `bass`, `drums` (= `kick` + `snare`), `hat`, `perc` (the groove's percussion: both hand layers in a hand groove), any voice name; variants `name:head` (first half of its cell), `name:tail`, `name:once` (first pass only), `name:last` (final pass only), `bass:groove` (the groove's line instead of the bass cell).
- **heat** (0 cold … 1 hot) is where each patch sits on its own journey in that section. Same notes at heat 0.1 and 0.9 are two different bodies.
- **moves**: if given, they replace the form's default moves. One to three.
- Lines are moved by octaves into their instrument's range automatically; unknown articulations are dropped.

## Breath reed and hand percussion: how to write for them

**Breath reed** (`feral-reed`, `smoke-reed`, `split-horn`). One player with one breath: never two notes at once.

- **Heat is breath.** `feral-reed` at heat 0–0.25 is a whisper (air, the pitch barely there), at 0.4–0.6 it sings, at 0.8–1 it growls and barks. Same notes, three creatures. That journey is called *whisper to feral*.
- **Whisper to feral, three ways:** (1) section heat: `"heat": { "lead": 0.1 }` early, `0.9` in the last section; (2) `timbreMorph` on the reed `from 0.05, to 1` over a section where its notes repeat; (3) `riffReturn` after a section without it. Use one.
- **Notes that touch are slurred** (no new attack). Leave a gap of a quarter beat where the tongue should re-start a note. Give every phrase a rest of a beat or more: a reed that never breathes is an organ.
- **Per-note articulations:** `breathy`, `tongued`, `accent` (a bark), `growl`, `flutter`, `scoop` (`"bend": 3`), `fall` (`"fall": 7`), `overblow` (a long note that cracks up into its upper register: once per track).
- Hooks sit best between D4 and D5. A whisper is quiet: keep three parts or fewer under it.

**Hand percussion** (`talking-skin`, `log-tongue`, `clay-whoop`).

- **The pitch chooses the drum** (one drum per written pitch, tuned to the key). Two or three pitches are a whole drum set: tonic low, fifth, octave.
- **The articulation is the hand, and it is most of the sound.** Skin: `bass` (palm boom), `open`, `slap` (crack), `tap` (ghost), `mute`, `roll` and `rub` (both last the length of the note; `rub` moans, add `"bend": 5`). Log: `strike`, `knuckle`, `rim`, `mute`, `scrape`. Pot: `whoop`, `drop`, `palm`, `tap`.
- **Heat is the room:** tight and dry cold, cavernous hot (a boom under the skin, long decays, rattling beads).
- **Easiest:** pick a hand groove (`hand-procession`, `clay-skip`, `twelve-hands`) and put `perc` in `play`: the groove brings the skin (or pot) and the log. To make a drum the hook owner or an answerer instead, give a voice the patch and write its cell with articulations.
- On a phone the low drum is felt, not heard. The slap, the log and the reed are what carry there.

## Two-sided tracks (a real tempo and time switch)

```json
{
  "title": "Two Faces", "key": "D minor", "seed": 7, "world": "one creature, two bodies",
  "voices": { "lead": { "patch": "feral-reed", "cell": { "bars": 2, "notes": [[0, 1.5, "D4", 0.8]] } } },
  "sides": [
    { "groove": "twelve-hands", "hook": "lead", "voices": { "bass": {} },
      "sections": [{ "id": "night", "bars": 8, "heat": 0.15, "play": ["perc", "lead"] }, { "id": "door", "bars": 4, "heat": 0.3, "play": ["bass", "drums", "perc", "lead"] }],
      "moves": [{ "move": "rollIn", "section": "door", "beats": 4, "step": 0.3333 }] },
    { "groove": "half-stomp", "hook": "lead", "form": "stallion", "voices": { "bass": { "patch": "chrome-grinder" } } }
  ]
}
```

- Each side overrides the top-level spec: its own `groove` (so its own BPM and swing), `hook`, `form` or `sections`, `moves`; `voices` are merged by name, so a voice written at the top is shared and a side may re-define it (a new cell for the new tempo, a new patch). One title, one key, one seed.
- Each side is built and critiqued as its own sketch (30–45 s each). They are rendered separately and joined on the bar line: side B's first downbeat lands exactly where side A's last bar ends, A's tail rings over it, and the quiet side stays quiet. Output: `score-a.json`, `score-b.json` and one MP3.
- **Earning the switch.** (1) Keep one thing across it: the same hook pitches in a new body. (2) Make the last bar of side A already belong to side B: `rollIn` in side B's pulse. Triplets (`"step": 0.3333`) at side A's tempo are eighth notes at 1.5 × that tempo: 96 → 144, 80 → 120, 72 → 108. (3) Side B's first sound is its heaviest and its hook starts on that downbeat. (4) Change tempo, feel and heat; do not also change the key.

## Moves (12)

### `floorDrop`
Drums fall to half-time (kick on one, snare on three), the bass shrinks to one long scooped note per bar with gear motion inside it, and the last bar keeps only its pickup.
- **Works when:** After the hook has been stated twice at full speed: the body expects the next downbeat and gets twice the room instead. Put ONE new thing above it (a cry, a drone).
- **Cheap when:** When nothing changes above the floor, or when it is the only idea in the track. A half-time section is not a breakdown unless something is exposed by it.
- Options: section, hat? (default true)

### `riffReturn`
The hook comes back whole on its owner, but the owner's body has changed: heat ramps to the top over the first half, first note re-struck harder, last note held and bent out.
- **Works when:** After a section where the hook was absent, broken or on another instrument. The notes are the ones the listener already owns; only the body is new. That is why it hits harder instead of just louder.
- **Cheap when:** If the riff returns at the same heat and register it is a repeat. If every other part also gets hotter it is a volume ramp. Change the owner, keep the room.
- Options: section, heat? (0.9), dive? (5 semitones), octave? (0)

### `displace`
Shifts a part against the drums by a fraction of a beat (wrapping inside the section), or loops its first `loop` beats so the cell rolls across the barlines.
- **Works when:** Once the listener knows the cell (two plain statements first). The drums stay put, so the ear hears the SAME thing land in the wrong place and leans in.
- **Cheap when:** When the cell is not memorable yet, when the drums move too, or when it never resolves back onto the one.
- Options: section, part? (hook owner), by? (0.75 beats) | loop? (cycle length in beats, e.g. 3.5)

### `negativeSpace`
Empties a window of the section: every part except `keep` stops and ringing notes are choked, so the hole is real.
- **Works when:** Right before the return, or under one exposed sound (keep: one voice). Silence is the loudest contrast the rack has; the next downbeat borrows its weight.
- **Cheap when:** As a reflex every four bars (it becomes a riser substitute), or when the thing after the hole is no bigger than the thing before it.
- Options: section, beats? (2), at? ("end" | "start"), keep? ([part ids that keep playing])

### `timbreMorph`
Ramps one part's heat across the section: the notes repeat while the patch travels cold -> hot (or back).
- **Works when:** On a figure that repeats unchanged: repetition becomes development because the body is moving. One part at a time.
- **Cheap when:** On everything at once (that is a filter sweep), or on a part whose notes are also changing (the ear cannot tell what moved).
- Options: section, part? (hook owner), from? (0.1), to? (0.9)

### `handOff`
The hook leaves its owner and is played by another part (ghosts dropped, re-registered, sung legato if it is a voice).
- **Works when:** When the new instrument changes what the hook means: machine -> human, low -> high, pluck -> breath. The listener recognises it and hears it differently.
- **Cheap when:** As an octave doubling with the owner still playing, or handed to a sound of the same family (tine -> marimba is a costume change, not a hand-off).
- Options: section, to (part id), keep? (false: the owner goes quiet / a bass owner drops to a pedal)

### `callAnswer`
Splits the hook: the owner plays the first half of each cell, the answer part finishes it in its own voice; the very last answer jumps up.
- **Works when:** When the two sounds have opposite attacks (pluck vs sung, dry vs ringing) so the hook becomes a conversation. Leave the gap between them.
- **Cheap when:** When the answer echoes the same notes every time, or both parts overlap so there is no question to answer.
- Options: section, answer (part id)

### `stopTime`
One bar where everything stops and the band hits a few unison stabs with silence between.
- **Works when:** Once, as punctuation at the end of a statement or as the door into a floor drop. The hits should outline the hook's rhythm.
- **Cheap when:** As the default fill, or more than once per track.
- Options: section, bar? (-1 = last bar), hits? ([0, 1.5, 2.5] beats in the bar)

### `stagger`
Parts enter one after another (at most `every` bars apart, always all in by the last bar). Default order is strangest first: textures and leads, then bass, hat, snare, and the kick last.
- **Works when:** For openings: the first sound heard defines the world, so lead with the one nobody expects and let the kick be the arrival.
- **Cheap when:** In DAW order (kick, hat, bass, lead): everybody has heard that build. Also cheap if nothing interesting is alone at the start.
- Options: section, order? ([part ids, first enters first]), every? (1 bar)

### `liftEnding`
The last bars of the section climb: bass and hook are transposed up a fourth, then a fifth, so the phrase ends leaning forward.
- **Works when:** Once, on the statement before a drop or a return: the harmony asks a question the next section answers (with the tonic, or with silence).
- **Cheap when:** On every phrase ending (it turns into a chord loop), or before a section that does not resolve it.
- Options: section, bars? (2), lift? ([5, 7] semitones: iv then V)

### `diveOut`
Ending gesture: the part's last note is held to the end of the section and bent down while everything else stops under it.
- **Works when:** As the final sound of the track or the last thing before a hole. It is a signature only if the piece has earned an ending.
- **Cheap when:** When it covers for a missing ending, or after a section that did not return the hook.
- Options: section, part? (bass, else hook owner), semis? (5), beats? (1.5)

### `rollIn`
The last beats of the section belong to one drum: everything else stops and a hand roll climbs from finger taps to slaps in the subdivision you name, the drum opening from tight to cavernous as it goes.
- **Works when:** Before a switch of groove, feel or tempo (the end of side A in a two-sided track). Roll in the pulse of what comes NEXT and the body learns the new tempo before it arrives, so the switch lands as an arrival, not an edit.
- **Cheap when:** As a drum-roll riser before every section, or into a section that is the same groove at the same size. A roll into nothing new is a fill, not a door.
- Options: section, part? (perc, else snare), beats? (4), step? (beats per stroke; default 1/3 = triplets), pitch? (semitones above the part's lowest drum, default 0)
