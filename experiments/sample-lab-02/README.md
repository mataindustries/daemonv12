# DAEMONV12 · SAMPLE LAB 02 / THE IMPOSSIBLE CRATE

Three short listening sketches. Each one starts from a new recording made for this lab and transforms it until it
sounds like something that shouldn't exist, while the source stays recognizable.

**Status: stopped for human listening feedback.** These are sketches, not songs. Only the strongest will get a full
production. No engine, Composer or site code was changed. Every render uses DaemonV12 0.7.0 as it is on `main`.
SAMPLE LAB 01 (`experiments/sample-lab-01/`) is untouched; its seamless-loop method is reused here.

**On a phone:** play the **×4 MP3**. It is the same loop four times with no gap, because many Android players pause
between repeats of a short file. Each 4-second MP3 (320 kbps, ID3-tagged) decodes to exactly one loop in FFmpeg. The
WAV (44.1 kHz, 16-bit, stereo) is the reference, and it wraps without a click.

[`TRANSFORMATIONS.md`](TRANSFORMATIONS.md) explains each unusual transformation and what to listen for, with
timestamps. [`SOURCES.md`](SOURCES.md) records where every sound came from.

## How it is built

```text
A  voice.ts (formant announcer) ─┐
   music-box interval signal ────┼─ ghost-sources.ts: SSB transmitter → fading sky → drifting receiver → AGC → speaker
   static, crashes, squelch ─────┘        = intercept.wav  (+ hum.wav)  ──engine──▶ ghost-frequency
B  object-sources.ts: mug, drips, box, book, coin (physical models in a small kitchen)
   mug.wav ──engine ×0.25──▶ mug-quarter.wav ──engine ×0.25──▶ bass   ┐
   drips, box, book, coin, mug (own pitch) ───────────────────────────┴──engine──▶ object-orchestra
C  whistle-source.ts: stairwell.wav (whistle + foot + snaps, one stereo take)
   ├─ offline reverse ──────────▶ stairwell-reversed.wav ─┐
   ├─ offline ×4 phase vocoder ─▶ stairwell-slowmo.wav ───┤
   ├─ engine ×0.25 ─────────────▶ whistle-quarter.wav ────┼─ engine (×0.25 again for the bass) ──▶ time-fracture
   └─ as recorded ────────────────────────────────────────┘
```

| Path | What |
|---|---|
| `scripts/dsp.ts` | Offline toolkit: seeded noise, filters, resonators, FFT, SSB frequency shift, stereo room, phase-vocoder stretch |
| `scripts/voice.ts` | The announcer: a Klatt-style cascade formant synthesizer |
| `scripts/ghost-sources.ts`, `object-sources.ts`, `whistle-source.ts` | Generation 0: the original recordings, with every chop point exported |
| `scripts/generate-sources.ts` | Writes all generation-0 files |
| `scripts/derive.ts` | The two offline generations: a bit-exact reverse and a pitch-preserving stretch |
| `scripts/ghost-frequency.ts`, `object-orchestra.ts`, `time-fracture.ts` | The scores: every event, offset, rate, gate and mix decision, with comments; plus the print projects |
| `scripts/score.ts` | Meter-aware tick helpers, adapted from SAMPLE LAB 01 |
| `scripts/build.ts` | The whole pipeline |
| `projects/*.json`, `projects/assets/` | The DaemonV12 projects and every audio file they read (`sources/`, `derived/`, `prints/`) |
| `deliverables/` | Per sketch: loop WAV, MP3, ×4 MP3, engine `.render.json`; plus `CHECKS.md` and `checks.json` |

## Rebuild

From the repository root, with Node 22.18+ and FFmpeg, after `npm ci`:

```sh
node experiments/sample-lab-02/scripts/build.ts
```

It takes about 45 seconds. It generates the sources twice and fails if they differ. It then derives the offline
generations twice, renders both prints, and renders each sketch as two cycles plus a bar of tail room, with a
three-cycle seam proof. Finally it rewrites `deliverables/` and `sources.manifest.json`. Two consecutive builds in this
environment (Linux, Node v22.22.0, FFmpeg 6.1.1-3ubuntu5) produced byte-identical files, all 44 of them.
Intermediate renders go to `work/`, which git ignores.

## Out of scope, and limits

No full songs, no visuals, no mastering beyond a gentle master compressor per sketch (about −14 LUFS, true peak at or
below −2 dBTP). I composed and checked these by measurement: pitch tracking, spectra, stem loudness and transient
contrast. **I cannot hear them.** Your ears are the gate. The "recordings" of objects, a whistler and a radio are
physical and acoustic models, not microphone recordings; `SOURCES.md` says exactly what each one models.
