# Cathedral Experiment · instrument reference

Generated by `node experiments/cathedral-experiment-001/instruments/docs.ts` (lab 0.1.0). Do not edit by hand.

Three new instrument families for the Signature Rack: THRONE//VOLT, CATHEDRAL//ENGINE and HEAVEN//MASS. They implement the rack's instrument interface and its calibration (a reference note at macro 0, velocity 0.8 renders at -20 dBFS RMS, so part gains compare across families), are deterministic (seeded) and use no recordings, samples, presets or impulse responses. **Not approved and not frozen**; licensing pending.

## Using them

They are registered per process, like the Timbre Lab, by loading the opt-in hook before the rack (the rack, its registry and the frozen engines are not edited):

```bash
node --import ./experiments/cathedral-experiment-001/instruments/register.ts studio-001/rack/cli.ts list
node --import ./experiments/cathedral-experiment-001/instruments/register.ts studio-001/rack/cli.ts render SCORE.json NEW_DIR
node --import ./experiments/cathedral-experiment-001/instruments/register.ts studio-001/rack/cli.ts kit throne-volt NEW_DIR --pitches 60-72 --macro 0.6
```

In a score they are ordinary parts, for example `{ "id": "lead", "instrument": "throne-volt", "macro": 0.6, "notes": [[0, 2, "Ab4", 0.9, { "articulation": "accent" }], [2, 2, "F4", 0.85, { "articulation": "legato", "slide": 0.3, "fall": 3 }]] }`. Controls accept a constant, `[[beat, value], ...]` ramps or `{ "steps": [[beat, value], ...], "glide": beats }`, either absolute (`controls`) or added to the macro mapping (`offsets`), and are clamped to the listed range. `expression` (0..1, 0.7 neutral) scales velocity as in the rack. The registry the hook installs lists the frozen rack instruments first, then the Timbre Lab, then these.

## smoulder → blaze · throne-volt

An analog-style lead and polysynth. One instrument; any number of voices (chords are separate voices, a legato note continues the voice nearest in pitch).

### `throne-volt` · THRONE//VOLT

Analog-style polysynth lead: a master saw, two drifting partner saws split left/right, a hard-synced scream oscillator and a sub square, through a hot mixer, a resonant 4-pole ladder with audio-rate growl, a throat colour and tube heat. Portamento, accents that sag the supply, held notes that bloom, releases that close the filter. Simulated at 2x and band-limited; deterministic.

Version `0.1.0+cathedral-experiment` · range C1–C7 (MIDI 24–96) · suggested gain -4 dB · macro `smoulder → blaze`

| Articulation | Effect |
|---|---|
| `normal` | velocity-shaped attack (harder = faster and brighter), gate 97 % |
| `accent` | hard attack: the filter spikes, the supply sags a few cents and recovers |
| `legato` | no new attack: the voice glides from the previous pitch (slide in beats, else setup glide) and the filter re-blooms a little |
| `swell` | slow brass-like swell of level and filter (about half a second) |
| `stab` | short and punchy (40 % gate) |
| `scoop` | starts below and rises into the pitch (param scoop, semitones, default 1.5) |
| `fall` | the pitch falls away at the end of the note, accelerating like a moan (param fall, semitones, default 3) |

| Control | Range | What it does |
|---|---|---|
| `cutoff` | 60 … 14000 | ladder cutoff in Hz at C4 (key-tracked from there) |
| `res` | 0 … 3.9 | ladder resonance (about 4 self-oscillates) |
| `env` | 0 … 6 | filter envelope depth in octaves (scaled by velocity) |
| `drive` | 0 … 1 | mixer and ladder input drive: thickness and grit before the filter |
| `heat` | 0 … 1 | asymmetric tube saturation after the VCA: even harmonics, density |
| `sync` | 0 … 1 | level and sweep of the hard-synced oscillator: the vocal scream |
| `detune` | 0 … 30 | partner oscillators, cents either side of the master |
| `sub` | 0 … 1 | square an octave below |
| `growl` | 0 … 1 | audio-rate filter FM from the sub: a snarl inside the tone |
| `vib` | 0 … 45 | vibrato depth in cents (arrives late in a held note) |
| `bloom` | 0 … 1 | held notes open up over about two seconds |
| `width` | 0 … 1 | partner oscillators split left/right (0 = mono) |
| `air` | 0 … 1 | breath of noise in the attack |
| `vowel` | 0 … 1 | two soft throat peaks (an open "aw") mixed after the filter |

Setup (per part): `seed` (0 … 4294967295: random seed (drift, slop, noise)); `glide` (0.005 … 1: default portamento time in seconds for legato notes without a slide); `attack` (0.001 … 0.2: base attack time in seconds (velocity shortens it)); `release` (0.02 … 3: release time in seconds (the filter closes with it)); `vibRate` (3 … 8: vibrato rate in Hz); `drift` (0 … 20: oscillator drift and attack slop in cents); `keytrack` (0 … 1: how far the cutoff follows the keyboard); `lowcut` (30 … 400: high-pass before the ladder in Hz (keeps the lows for the 808)).

Per-note parameters: `scoop` (semitones to rise from on a fresh attack); `fall` (semitones the pitch falls over the end of the note); `fallBeats` (length of the fall in beats (default: the last 45 % of the note, at most 1.5 beats)); `cents` (fine tuning of this note in cents (e.g. just-intoned chord tones)).

## whisper → full organ · cathedral-engine

A synthetic pipe organ in three divisions. Write one part per division; notes are written at 8' pitch (a 16' rank sounds an octave lower, a 4' an octave higher). Every rank is a continuous control (a drawstop that can move mid-phrase); the macro is a crescendo pedal.

### `cathedral-engine/great` · CATHEDRAL//ENGINE Great

Unenclosed main division: principal chorus 8-4-2 2/3-2, Mixture IV, Bourdon 16' and Trumpet 8'. Pipe-by-pipe synthesis: per-harmonic speech, chiff and mouth noise, voicing and tuning scatter, a shared wind system that sags under big chords, C/C# chest layout, and the Nave space (high-passed tail). The macro is a crescendo pedal: stops enter in order.

Version `0.1.0+cathedral-experiment` · range C2–C7 (MIDI 36–96) · suggested gain -6 dB · macro `whisper → full organ`

|---|---|
| `normal` | organ legato touch (gate 98 %) |
| `detached` | non-legato (gate 78 %) |
| `staccato` | short (gate 45 %) |

| `marcato` | fast key: crisp speech, strong chiff and reed blat |

Per-note parameters: `sag` (cents the note droops over its last 40 % as the key is let up slowly (pallet half closed), max 100); `cents` (fine tuning of this note in cents); `chiff` (speech transient multiplier for this note).

## intimate → heavenly · heaven-mass

A synthetic choir in four sections. Write one part per section (or more, for divisi); each part is an ensemble of individually different singers. Vowels are per note (`vowel`, `to`); the macro grows the ensemble from intimate to heavenly.

### `heaven-mass/bass` · HEAVEN//MASS Bass

Basses (C2-E4): the longest tract and a clustered ring, fundamentals lifted and the low mids carved; optional octavists an octave below for depth without mud. An ensemble of individually different singers (tuning, drift, vibrato, timing, tract, breath, seat) on an additive source-filter voice with this section's own formants; singers join as the ensemble grows; breath, air and the Nave.

Version `0.1.0+cathedral-experiment` · range C2–E4 (MIDI 36–64) · suggested gain -3 dB · macro `intimate → heavenly`

| Articulation | Effect |
|---|---|
| `sung` | fresh onset: a small scoop and the singer settles into tune |
| `legato` | glides from the previous note (slide in beats, else about 75 ms) |
| `hum` | closed "mm" unless a vowel is given |
| `swell` | slow bloom onset (about 0.4 s) |
| `detached` | shorter (80 %) |
| `fall` | sighing fall at the end (param fall, semitones, default 1) |
| `breathy` | extra breath at the onset |

| Control | Range | What it does |
|---|---|---|
| `ensemble` | 0 … 1 | how many of the section's singers sing (singers join one by one) |
| `breath` | 0 … 1 | aspiration in the tone and the depth of the inhales before phrases |
| `air` | 0 … 1 | unvoiced sheen above 5 kHz that follows the singers: height without harshness |
| `effort` | 0 … 1 | vocal effort: brighter, richer source as it rises |
| `vib` | 0 … 2 | vibrato depth scale (each singer keeps their own rate and depth) |
| `width` | 0 … 1.2 | how far the singers spread around the section's seat |
| `room` | 0 … 1.5 | send to the Nave |
| `octavist` | 0 … 1 | octavists an octave under the basses (bass section only) |
| `tract` | -1 … 1 | throat size: -1 giant (formants down 15 %) .. 1 small (up 15 %) |

Setup (per part): `seed` (0 … 4294967295: random seed (who the singers are)); `singers` (1 … 12: singers in the section (default 6)); `octavists` (0 … 4: octavists under the basses (default 2; bass section only)); `tuning` (0 … 25: spread of the singers' tuning in cents (default 5)); `timing` (0 … 60: spread of the singers' onsets in ms (default 18)); `depth` (0 … 1: distance in the Nave: pre-delay, size and decay grow with it (default 0.5)); `lowCut` (40 … 500: high-pass on the room tail in Hz (default 140)); `center` (-1 … 1: override the section's seat in the stereo field); `centre` (0 … 1: section tuning centred on the written pitch (1, default) or free (0: every singer's own offset)); `output` (text: "mix" (default: voices plus the Nave), "dry" or "wet").

Per-note parameters: `vowel` (one of mm, oo, oh, aw, ah, uh, eh, ee); `to` (vowel reached by the end of the note); `fall` (semitones); `scoop` (cents below the pitch where the onset starts (default per singer 15-45)); `cents` (fine tuning of this note in cents (just-intoned chord tones)).
