# SAMPLE LAB 01 · Source manifest, rights and provenance

Both candidates read the same eight-sound palette. Nothing else enters either loop except two prints that are
themselves made only from that palette. The machine-readable version, with every SHA-256, is
[`sources.manifest.json`](sources.manifest.json), written by `scripts/build.ts`. This is evidence, not legal advice.

**CC0 sounds.** Copied byte-for-byte from `examples/assets/`. The build refuses to run unless each copy matches the
SHA-256 in its pack catalog (`examples/glasshouse.catalog.json`, `examples/orbital-foundry.catalog.json`). Both packs
carry a CC0 1.0 LICENSE that allows commercial use without attribution, and both were generated in this repository from
code alone (PR #6 and PR #11). They were independently regenerated byte-for-byte in the BANGER LAB 001 rights audit. The one
open item from that audit still applies: the owner should record that the CC0 dedication is theirs.

**New sources.** `scripts/generate-sources.ts` uses only Node built-ins and fixed xorshift32 seeds. It reads no files,
recordings or network data. Every build generates them twice and fails unless both runs match the committed bytes.

- `keys-take.wav` (11.0 s, stereo): one player at 100 BPM playing Dbmaj9, Bbm9, Ebm11 and Gbmaj9 in close rootless
  voicings between F3 and Bb4. Each chord is rolled over 14–38 ms with per-note velocity and ±2 cent detune, and each has
  one inner-voice move halfway through. The voice is an FM tine-and-pickup model: a 1:1 FM body whose index follows
  velocity, a short inharmonic tine, an asymmetric pickup curve and a damper thump. The signal chain is a 4.4 Hz suitcase
  tremolo, a lightly driven amp, a small synthetic room and a tape-like roll-off. There is no bass register.
- `bass-db.wav` (3.2 s, mono): two band-limited saws ±3 cents apart and a sub-octave square, through a driven four-pole
  ladder with a plucked filter envelope.

**License for the new sources:** not yet declared. This is the owner's decision; CC0-1.0 is proposed so they match the
existing packs. They contain no third-party material.

**CRATE-01** is the record both candidates chop. It is a drumless, four-bar soul passage at 100 BPM: the keys take,
a two-voice ghost-vox group singing "oh-ah" twice a bar (F4 Eb4 | F4 Db4 | Gb4 F4 | F4 Eb4 over thirds and sixths), glass
doubling the top line and a low air bed, glued with gentle compression, saturation and a 10.5 kHz roll-off. Its exact
chop regions (`Bbm9-oh`, `Gbmaj9-ah`, …) are exported by `scripts/crate-01.ts`; the event maps name the region each chop
reads. **GLASS CHOIR** is a single hybrid note (voice + octave-down voice + glass through one room). B plays it as an
instrument, so its baked room is chopped and repitched with every hook note.

## Excluded on purpose

| Source | Why |
|---|---|
| MORPH v1 pack (`examples/assets/morph-v1/`) | Its README and `docs/MORPH_SOUND_AUDIT.md` say no license grant is asserted and that rights must be decided before external distribution. The brief allows MORPH sounds only "whose rights are documented", so none are used. |
| FluidR3 GM SoundFont (`gm` instruments) | Excluded by the BANGER LAB 001 rights audit: its public-domain sample sources are unidentified. |
| Any commercial, downloaded or third-party recording | Not used anywhere. Every sample in this lab is a pure function of code in this repository. |

## The compositions

The progressions, chop arrangements, basslines, drum programming and hooks were written for this lab. The production
principles named in the brief (collage, unquantized feel, resampling) guided the process; no existing recording,
melody or arrangement was copied or referenced. As in the BANGER LAB 001 audit, both loops should get a human
resemblance check during listening, and the owner should record the human creative direction before any licensing.
